# Contributing

Read [requirements](docs/PRODUCT.md) and [Cursor handoff](docs/CURSOR-HANDOFF.md). Branch from the agreed base; use `codex/` for Codex branches. Make small commits grouped by purpose. Preserve attribution and image provenance.

Never commit credentials, customer data/images, node_modules, or build output. Include actual verification commands/results in PRs, separating passing, failing, and skipped checks. Explain migrations, configuration, and rollback impact. Update documentation when agreed decisions change. Request review before merging.
